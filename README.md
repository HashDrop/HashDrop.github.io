# HashDrop

> Free, no-login temporary file uploader and ChatGPT file bridge.

**Upload → Hash → Use → Expire**

HashDrop lets you upload a file without creating an account, get a temporary hash, and use the file wherever you need it.

Built for people who are tired of failed uploads, unnecessary sign-ups, permanent file storage, and complicated file-sharing services.

## What HashDrop Does

- 🚫 No account
- 🚫 No login
- 🚫 No email
- 📁 Up to 500 KB per file
- 🔄 New uploads replace the previous file
- ⏱️ 30-minute inactivity expiration
- 🤖 Works as a bridge for ChatGPT
- ♾️ Designed for repeated temporary uploads

**Upload a file. Get a hash. Use it. Done.**
